# Blog site design and experiment contract

The canonical essay addresses PS topic 9, observability constraints in latent reasoning. Output evidence, intervention evidence and mechanism evidence remain distinct. The toy provides an intervention instrument, not an imitation of proprietary BDH-CQ.

## Tokens before implementation

- Mineral paper `#edf2f4`: page background.
- Deep ink `#243b4a`: text and observed activation density.
- Slate `#637785`: secondary information.
- Specimen white `#ffffff`: essay and sealed specimen.
- Changed blue `#176bc4`: learner interventions and focus.
- Failure plum `#814f72`: incompatible or ambiguous evidence.

Typography uses the existing bundled Manrope OFL font for both reading and controls. Reading measure is 70 characters. No remote font or network dependency. The microscope's existing palette remains unchanged on its own pages.

```text
artifact navigation

quiet essay, 70-character measure
  paper counts beside failures and caveats
sealed specimen, output + oracle + intervention controls
  hidden mechanism until explicit unseal
finite fault round and identifiability result
synthesis relations / references / provenance / PDF
```

## Principles

One visually strong element: the specimen. All surrounding material is a restrained long-form document. Numbered citations expose locators on keyboard focus and hover. No claims depend on animation. Reduced motion is honored. Machine-readable claim records carry scope and status, not just prose. The PDF uses the same Markdown import as the webpage, while the submitted v1 PDF remains frozen.

## Experiment semantics

True-world BFS and visible-context BFS are independently computed on fact edges. The neuron simulation is monotone integrate-and-fire, not BFS. Code overlap may make its decoded frontier disagree with both oracles. A finite fault round compares coverage, compute and binding hypotheses under the displayed action menu and budget. Its exhaustive output-trace enumeration includes the initial observation and all sequences up to the budget. Identifiability is relative to that menu, not a claim about arbitrary interventions or proprietary systems. An intentionally restricted control-only round leaves coverage and compute observationally equivalent.
